the method or assigns the handler; "via" means a sample uses a higher-level SDK call that sends it.

The .NET columns are taken from [hyssostech/sketch-thru-plan-sdk-net](https://github.com/hyssostech/sketch-thru-plan-sdk-net), branch `claude/STP-1797-net-512-calls` at commit

branch's `docs/articles/contract-name-mapping.md`; a .NET sample is listed when its code calls the method or subscribes to the event.
"pending (STP-1802)" marks an item no .NET sample shows yet; "-" in the .NET SDK column means the .NET SDK has no member
for it at that commit.
